Heatsink Loading / Repacking

Operations & maintenance manual · 운영·유지보수 매뉴얼

What it does. Scan a box barcode, take 2 photos (the barcode shot + 1 more), and the app builds a daily PDF (one box per page: full ID + photos) and uploads it automatically to Google Drive.
박스 바코드 스캔 → 사진 2장(바코드+1장) → 하루치 PDF 자동 생성·드라이브 업로드. 박스당 1페이지(풀 ID + 사진).

1. Daily use · Uso diario

  1. Tap “+ New box.” Toque “+ New box”.
  2. Point at the bottom barcode (Code 128, not the QR). It reads automatically. Apunte al código de barras inferior; se lee solo.
  3. Take the remaining photo(s). At the last photo it saves automatically. Tome las fotos restantes; se guarda solo.
  4. The box appears with a green check. That’s it — the PDF uploads by itself. Aparece con una marca verde; el PDF se sube solo.

Tips if a barcode won’t read: move ~15–20 cm away, pinch to zoom, tap the screen to focus, or turn on Torch. Clean the lens.
안 읽히면: 15~20cm, 핀치 줌, 화면 탭(초점), Torch. 렌즈 닦기.

2. Upload status · is it working?

The banner under the buttons shows the state:

BannerMeaning
Waiting to upload…A change was made; it will upload after a short pause.
Uploading to Drive…Sending now.
Auto-uploaded 17:32Last successful upload time. All good.
Upload failed – retryingWill retry in 60s. Check Wi-Fi / token (Settings → Test).
Auto-upload offNo Drive URL set. Add it in Settings, or use Export PDF (share sheet).

3. Recover a missed day · 안 올라간 날 복구

Use the ◀ date ▶ bar to go to a past day, then press Export PDF. It rebuilds and uploads that day’s file. New scans always go to today.
날짜 화살표로 과거 날짜 이동 → Export PDF 누르면 그날 파일 재생성·업로드. 새 스캔은 항상 오늘로 저장.

4. Settings reference · 설정

Open with the ⚙️ icon (top-right). Each app (Loading / Repacking) has its own settings.

FieldWhat it does
Drive upload URLThe Apps Script web-app URL (ends in /exec). Enables auto-upload.
TokenMust match the TOKEN in the script. A shared password.
Keep daysDays of history kept on the phone; older is auto-deleted. Default 7.
Photos per boxTotal photos incl. the barcode shot. Default 2.
PDF file name prefixOverride the file name start. Blank = default (Heatsink_Loading_ etc.).
Barcode type(s)Comma-separated (e.g. CODE_128). Add others if labels change.

Diagnostics section shows version, storage used, last upload, camera status, device. Screenshot this when reporting a problem.
진단 섹션 = 버전·용량·마지막 업로드·카메라 상태·기기. 문제 신고 시 이 화면 스샷 하나면 됨.

5. First-time setup · 최초 설정 (admin)

Install the apps

  1. Download the two APKs (app-loading-debug.apk, app-repacking-debug.apk).
  2. On the phone, allow Install unknown apps for your file manager, then tap each APK.
  3. Two icons appear: Heatsink Loading and Heatsink Repacking.

Set up Google Drive auto-upload

  1. Make a Drive folder. Copy its ID from the URL: drive.google.com/drive/folders/THIS-PART (stop at ?).
  2. Go to script.google.com → New project → paste DriveUpload.gs.
  3. Fill FOLDER_ID and TOKEN (any secret string).
  4. Deploy → New deployment → Web app → Execute as Me, Access Anyone → Deploy → authorize.
  5. Copy the web-app URL (ends in /exec).
  6. In the app: ⚙️ → paste URL + the same TOKEN → Test → Save. Repeat for the other app.

Own the script with a shared/team Google account, not a personal one — if that account is disabled, uploads stop. (스크립트는 팀 공용 계정 소유 권장.)

6. Admin / developer tasks · 관리자

TaskHow
Change target Drive folderEdit FOLDER_ID in the script → Deploy → Manage deployments → edit → New version → Deploy (URL stays the same).
Change photos / file name / barcode typeNo rebuild — do it in the app’s ⚙️ Settings.
Rebuild the app (code change / OS fix)Push to GitHub → Actions builds both APKs → download heatsink-debug-apks.
Add a new task modeAdd a product flavor in android/app/build.gradle + a mode.js override, or ask the developer.

APK updates: debug builds may be signed differently between builds; if an update won’t install over the old one, uninstall first (this loses on-phone history, but Drive copies are safe). Ask the developer to set a fixed signing key to make updates seamless.
업데이트가 덮어설치 안 되면 기존 앱 삭제 후 설치(폰 기록은 날아가지만 드라이브 원본은 안전). 고정 서명 키를 넣으면 이 문제 없어짐.

7. Troubleshooting · 문제 해결

ProblemFix
Barcode won’t scanGet closer (15–20cm), pinch-zoom, tap to focus, Torch on, clean lens. Low-end phones need more light.
“Upload failed”Check Wi-Fi. ⚙️ → Test. Confirm token matches the script. Confirm the web-app is deployed (open the URL in a browser → should say ready).
File not in DriveCheck the correct app’s settings point to the right URL/folder. Use ◀ to that day → Export PDF to resend.
Wrong box savedTap the box → Delete or Re-shoot.
Storage worryAuto-cleans after Keep days. Lower it in Settings, or Clear day.
Wrong date on filesFix the phone clock (use network time).
Camera shows MISSING in DiagnosticsReinstall the APK; report to developer with the Diagnostics screenshot.
